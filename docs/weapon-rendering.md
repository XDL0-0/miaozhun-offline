# Weapon material and resource changes

The skin geometry and surface maps were already loading. The reported plain appearance exposed differences in the shading pipeline: all skins shared a 16×8 grey reflection map, and their exported tangent directions were discarded. The source normal maps already contain reconstructed blue channels and remain linear data.

The importer now retains original weapon HDR environment panoramas. Twenty-six visible material assignments use their explicit source HDRI; 109 use the original first-person weapon studio as a documented fallback. Nine hidden materials allocate no environment. Fourteen source records produce thirteen unique runtime payloads because two source panoramas are identical. Explicit HDRI strength/brightness takes precedence over the separate inherited probe parameter; unknown shader operations and rotation units are not invented.

Environments use linear RGBA16F, gzip storage, equirectangular mapping and the renderer's existing PMREM filtering. Oversized environments receive linear area averaging to at most 1024×512; the original RGBE files and hashes remain in `skin-packs/environments/originals/`. Gun body maps retain their original 2K/4K sizes. Original HDR hotspots exceed SDR white, so only the custom weapon materials receive a local filmic highlight curve before output conversion. This is an approximation of the display response, not Riot's cooked custom shader. It does not change world exposure, add bloom, or draw screen-filling cards.

The GLB decoder preserves and orthogonalizes original tangent directions. CUE exports write a constant positive tangent handedness, including mirrored UV islands. The decoder reconstructs handedness from the geometry/UV bitangent and splits conflicting seam vertices, copying normals, UV sets, joints and weights. Triangle counts and animation bindings remain unchanged. `node scripts/verify-weapon-tangents.mjs` independently checks every retained GLB; [the audit](../skin-packs/audit/weapon-tangent-validation.json) covers all 867,504 triangle corners and the attributes of every copied vertex.

Live controllers share immutable textures by source URL and color space, using reference-counted leases. Disposing one controller cannot dispose a texture still used by another. Hidden materials no longer preload their unused body maps. The raw model cache has a 96 MiB budget and a four-entry ceiling; the most recent single model can exceed the budget, and live controllers retain the assets they use. This bounds historical cache retention rather than all process or GPU memory.

Static original-size RGBA8/mipmap estimates show about 5.33 MiB of shared body maps for the 2026 Champions rifle/fan pair and 7.01 MiB for the two Kuronami rifles. Some other pairs share no body maps. These figures exclude environments, drivers and the rest of the scene; they are not FPS measurements.

`node scripts/profile-weapon-models.mjs` creates a temporary `/__weapon-profile.html` page using the delivered renderer and memory-only skin choices. It records warmed update/submission times, frame intervals, asynchronous GPU timers where supported, draw calls, texture identities and resource requests. It does not modify training preferences or scores. The weapon-only benchmark cannot represent a complete training scene. This revision has no browser benchmark or rendered acceptance result: desktop inspection was blocked because the computer tool could not reliably determine the Edge URL. The previous Champions screenshots and action report predate these material changes.

Source parameters, original/runtime hashes, HDR statistics and fallback assignments are recorded in `skin-packs/audit/weapon-model-sources.json`. Unit tests cover HDR conversion and integrity, local loading, tangent orientation/seam splitting, animation weights, texture ownership, cache eviction and shader configuration. Offline verification covers the delivered local resource closure.

Current validation: 168 tests passed, no failures or skips. The local verifier passed 2,824 resources, 62 scenes and six maps without required missing assets. The existing two optional Outlaw equip resources remain outside the delivered source set. See [the current validation record](../skin-packs/audit/weapon-rendering-validation.json).
