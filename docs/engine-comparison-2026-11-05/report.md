# 新旧引擎固定场景性能对比

新版相对旧版的三轮中位数变化：亚海悬城渲染提交 CPU -32.28%、1% low -18.67%；天枢云阙渲染提交 CPU +4.29%、1% low -3.34%。CPU 提交更快不等于画面更流畅，应结合每轮波动判断。

全部 12 组结果通过校验：2 个场景，每场景 3 对；第 1、3 轮 old → new，第 2 轮 new → old。以下为描述性结果，不作统计显著性结论。

比较对象为升级包整体，包含引擎与地图资源的版本变化；即使场景文档相同，也不能把差异因果归因于某段引擎代码或某个新增功能。旧版已有 batching/PVS。本次不包含压力测试或原生无限帧率测量，预跑（pilot）不纳入统计。

测试在后台不展示的 Codex 内置浏览器（IAB）运行，但采样首尾及事件记录中的 document.visibilityState 均为 visible，以避免隐藏文档节流。绘图缓冲为 1280×720；每组 5 秒模拟预热 + 15 秒模拟采样，固定场景和随机种子 20261105。采样以模拟时钟为准，首帧就绪前的启动暂停不计入这 5 秒模拟预热；记录实际墙钟时长，不按墙钟恰好 15 秒筛除慢帧。

实际采样墙钟时长为 14.985–15.021 秒，模拟时长为 14.984–15.016 秒。每组模拟采样时长须在 15±0.05 秒、总模拟时长在 20±0.05 秒内，采样墙钟与首末渲染跨度均须至少 14.9 秒；墙钟没有 15/20 秒上限。

保留两版原生 WebGL context 设置：old stencil=false，new stencil=true；新版使用 stencil，因此没有强制改成相同值。每对测试的 GPU、UA、缓冲尺寸及其余 context 属性严格一致。stencil 差异属于升级包的一部分，结果不能解释为隔离 stencil 后的纯引擎代码效应。

两版都使用 requestAnimationFrame 调度，当前环境约受 60 Hz 限制；这里的 FPS 是渲染回调间隔指标，不能推断原生无限帧率上限。CPU 数值仅覆盖逻辑 tick 和渲染提交的同步耗时，不包含异步 GPU 完成时间，也不是全进程 CPU 利用率。

所有有效样本均保留：各轮原生绘制提交频率为 31.57–59.93 次/秒，独立 RAF 回调为 59.40–60.00 次/秒。原生调度保留 GPU fence 队列限流（默认最多 2 帧在途），可在进入渲染回调之前跳过绘制；这与 CPU 提交耗时降低可以同时发生。本次没有直接计数 GPU 等待或测量 GPU 完成时间，不能据此断定 GPU 算力瓶颈或归因于某个改动。

测试后的隔离端口存储核对见 [environment-audit.json](environment-audit.json)；这不属于逐帧遥测。

音频及回放录制关闭，原生外观和默认 Vandal 枪械；无全屏、无指针锁定。输入脚本包含转向、开火、换弹、切换武器和检视，不包含玩家移动。阴影开启，renderScale=1，lowLatency=false。
